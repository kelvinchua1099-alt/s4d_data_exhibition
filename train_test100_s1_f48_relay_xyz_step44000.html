约定

除帧数和块数外和 23 帧两块接力页的主行完全相同（同一个评测脚本、同样的 3D 交接和拼接），那页的约定表逐条适用；前两块的推理和 23 帧页是同一回事，差别只在打分时整段对齐用的帧更多。

项约定
数据4RC/data/s4d_test100_s1_f48 全部 48 帧（源帧 0–47 连续，1280×720），query = 第 0 帧前景 mask 内每 4 像素取 1 个，真值在第 0 帧相机系、米制
切块stride = 13 − 3 = 10：块 k = 帧 10k – 10k+12（末块截到 47）；拼接行的共享帧照 Point4D 默认的 overlap_strategy="smooth" 混合（帧 10k 取块 k−1、10k+1 两块各半、10k+2 取块 k）；逐块对 GT 行和旧版拼接行的共享帧归前一块，块 k（k ≥ 1）贡献帧 10k+3 – 10k+12
3D 交接eval_point_track_relay.py --handoff xyz：块 k+1 先前向一次拿深度云，和块 k 在 3 个共享帧上的深度云配对、按 Point4D _chunk_sim3 估块 k → 块 k+1 的 Sim(3)，块 k 在交接帧（块 k+1 的第 0 帧）的预测 3D 经它搬过去当块 k+1 的起点，再前向一次；query 像素 = 起点 3D 投影、裁到画内（patch 从这里裁，原版沿用出生处 patch）
块间拼接（打分）照 Point4D track_long_video：块 0 不动；块 k−1 → 块 k 的 Sim(3) 就是 3D 交接时共享帧深度云估的那个，从块 0 起链式复合、取逆把块 k 搬到块 0 第 0 帧相机系，共享帧按上面的权重混合（rescore_point_track.py --stitch --stitch_mode point4d）。误差会沿 4 个接缝累积。只用模型自己的预测，不碰 GT。旧版拼接（灰色行，这页之前的主行）：块 k 在和块 k−1 共享的 3 帧上与已拼好的轨迹点逐点配对，拟合一次 RANSAC Sim(3)（1000 次 3 点、内点 5 cm 模型单位、精化，--stitch_mode tracks）——只有前景点、而且把两块轨迹在共享帧上的差异吸收进对齐里，不是 Point4D 的做法
打分4RC track_eval.py 口径（avg_pts = 0.1 / 0.3 / 0.5 / 1.0 m 内比例的平均，dyn 只算总运动 > 0.01 m 的点，EPE 全部点·帧平均），全部 RANSAC Sim(3)：拼接 / 整段行整段一次，逐块对 GT 行每块一次（借 GT 的尺度和位姿，是拼接完美时的参照）。survival 同 PIPs++ 口径。RANSAC 没设种子，汇总表另给 5 次重复打分的均值 ± std
3D 查看器GT（黑）与两个模型 3D 交接 + 块间拼接后的轨迹（整段一次 RANSAC Sim(3) 对齐到 GT），每段最多 300 条、GT 相机视锥；右下角逐帧平均误差曲线（帧 13 / 23 / 33 / 43 起换块）

接缝诊断

每个接缝、每种拼接一行。块间尺度 = 拼接时块 k → 块 0 的尺度（深度云拼接 = 链式复合的深度云 Sim(3) 取逆，旧版 = 轨迹点 RANSAC Sim(3)）；出界 = 尺度 <0.5 或 >2 的段；拼接残差 = 块 k 搬过去后（混合前）共享帧上两块轨迹预测的距离中位数 ÷ 块 0 第 0 帧预测深度中位数（旧版是在这些点上拟合的，残差天然小）；块 k 损失 = 块 k 独有帧上的 avg_pts（拼接 − 逐块对 GT）；裁到画内 = 交接时起点 3D 投到画外被裁回的 query 比例。
