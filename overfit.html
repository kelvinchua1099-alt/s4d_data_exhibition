VGGT-Omega + motion head 全量微调，只用 4 个训练样本训练 2000 步，再用同一批样本前向，验证训练管线能不能把它们拟合住。每段视频左边是网格真值轨迹，右边是模型预测。

训练与可视化约定

项约定
样本一个样本 = 一个世界的一台相机从起始帧开始的 12 帧片段；预处理时源视频每 17 帧取 1 帧（30 fps → 1.76 fps，相邻两帧约 0.57 s），画面 512×288
query 点片段第 0 帧前景 mask 内固定种子取 64 个像素，按深度反投影到 3D
真值轨迹每个 query 点挂到最近的网格三角形上随网格逐帧搬运，表达在第 0 帧相机系里
前向与训练相同：链式追踪 11 跳（0 → 1 → … → 11），链的起点用真值 3D query、投影用真值相机（teacher forcing）。看的是 loss 拟合到的东西，不是纯推理
画法同 Point Tracking 页：颜色按 query 点在第 0 帧的横坐标；左 GT 实心 = 可见、空心 = 被遮挡；右为预测，标题栏是该帧平均 3D 误差。两边都用真值相机投影。预测与真值同尺度，不做 Sim(3) 对齐
