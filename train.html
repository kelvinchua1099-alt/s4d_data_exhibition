s4d_train 全量微调 · 测试集检查

VGGT-Omega + motion head 在训练集（768 段、430 个世界）上全量微调 32000 步，取 checkpoint 在模型没见过的测试集（360 段、212 个世界）里均匀抽 12 段前向。每段视频左边是网格真值轨迹，右边是模型预测。

12测试样本（12 个世界）
32000优化步数
43.6 cm平均 3D 误差（全部帧、全部 query）
18.25 px2D 投影误差中位数（各样本平均，512×288）

训练与可视化约定

项约定
训练训练集每段每隔 3 帧取一个起始帧，一个样本 = 一台相机从起始帧开始的 12 帧片段，随机分辨率（长边 336–504）。8 卡，每卡 1 个样本，梯度累积 2，共 32000 步；config 见页脚
测试样本测试集按样本编号等间距抽 12 段，世界与训练集不重叠；预处理时源视频每 4 帧取 1 帧（30 fps → 7.50 fps，相邻两帧约 0.13 s），画面 512×288（原生分辨率，不做随机缩放）
query 点片段第 0 帧前景 mask 内固定种子随机取 300 个像素（训练时每样本 64 个），按深度反投影到 3D
真值轨迹每个 query 点挂到最近的网格三角形上随网格逐帧搬运，表达在第 0 帧相机系里
前向与训练相同：链式追踪 11 跳（0 → 1 → … → 11），链的起点用真值 3D query、投影用真值相机（teacher forcing），不是纯推理
画法同 Point Tracking 页：颜色按 query 点在第 0 帧的横坐标；左 GT 实心 = 可见、空心 = 被遮挡；右为预测，标题栏是该帧平均 3D 误差。两边都用真值相机投影。预测与真值同尺度，不做 Sim(3) 对齐

全部 12 个测试样本

视频按实时速度播放（7.50 fps，12 帧约 1.6 s），拖尾为最近 2 帧（约 0.3 s）。第 0 帧画的是 self-query（模型直接回归 query 像素的 3D 位置）。

与公开模型的 12 帧对比

数据与打分同 Point Tracking 四模型对比页（s4d_sample100 的 100 段、第 0 帧可见前景点做 query、整段 Sim(3) RANSAC 对齐、固定阈值取 avg_pts），只把 --num_frames 从 64 改成 12：每段只取前 12 帧（源帧 0–44，7.5 fps 约 1.5 s），和 s4d_train 训练用的 12 帧片段对齐；五个模型吃同样的 12 帧。s4d_train 在这里是纯推理：不给真值 query 3D、不给真值相机，链从模型自己对 query 像素的 3D 估计出发，下一跳的位置用 camera_head 预测的相机投影，输入缩到 512×288。100 段里 67 段的世界在 s4d_train 的训练集里（其余模型没见过任何一段），所以表格以 29 段测试集为准。
