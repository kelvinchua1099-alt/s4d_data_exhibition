锚点 + 段内短链 · 100 帧

跳帧一条链在关键帧上很准，但只有关键帧有预测。这页把它补成每一帧都有：每隔几帧取一个锚点，锚点之间用跳帧片段（只含锚点帧、相邻跳）走一跳；非锚点帧从它所在段的锚点出发、在逐帧片段上逐帧走（例：帧 14 = 0 → 6 → 12 → 13 → 14）。History v2 · step 44000，第 0 帧深度反投影起点，对比同起点的 Point4D head 12/3 接力。主结果再把每段路径单独组成一个片段前向（路径片段：帧 62 所在段 = [0, 6, …, 60, 61, 62]），让每一跳的 memory 只有路径上的十几帧。走法是因果的（第 t 帧只用到 ≤ t 的帧），可以在线跑。

约定

项约定
数据s4d_test100_s1_f100：100 段测试集、连续 100 帧，query 点为第 0 帧可见的前景点（同 100 帧接力页）
模型与起点s4d_train 上训到 step 44000 的 History head v2（history_abl_v2_step44000_depth）与 Point4D head 消融。起点都是第 0 帧 dense_head 深度 + 预测内参在 query 像素处反投影，各用各模型的深度
锚点走法锚点每 k 帧一个（0, k, 2k, …）。锚点 a 的上一跳取能整除 a 的最大跳距 J，从锚点 a − J 出发、在跨 J 帧的跳帧片段（filelist[::J]，相邻跳 = 训练见过的跳法）上走一跳；非锚点帧从段首锚点在 100 帧逐帧片段上逐帧走。几种片段第 0 帧相同、backbone 因果，共用第 0 帧相机系和尺度（深度起点逐点相对差中位 2e-5–2e-4）。每个下一锚点同时有"段内逐帧链"和"跳帧一跳"两个估计：主结果取跳帧一跳，"取平均"行取两者平均。路径片段（--path_clips）：跳法相同，但不用跳帧片段 / 100 帧逐帧片段，每段路径（锚点路径 + 段内帧）单独组一个片段前向，锚点取它所在段的片段里的结果；6 链 + 一跳（--last_hop direct）：段内每帧从锚点直接一跳，每帧一个路径片段
12/3 接力沿用 100 帧接力页的预测：12 帧一块、相邻块共享 3 帧，3D 交接 + 共享帧深度云 Sim(3) 拼成一条（point_track_relay_f100_c12o3_xyz_dstitch）。Point4D 接力只有第 0 块从深度起点出发，之后每块从交接过来的 3D 点出发
打分每段在 100 帧全部点上一次 RANSAC Sim(3) 对齐到 GT（4RC 口径），avg_pts = 误差在 0.1 / 0.3 / 0.5 / 1 m 内的比例取平均，逐段平均；EPE = 对齐后平均距离（米）；survival 是 PIPs++ 口径。estimate_sim3 没播种，每个方案打 5 次取平均，± 是 5 次的标准差。逐帧分数用整段那一次对齐。逐段胜负用 5 次平均后的逐段 avg_pts，差 > 0.005 算高 / 低
跳数 / 帧次每帧跳数 = 锚点跳数 + 段内逐帧跳数（帧 1–99 的平均 / 最多）。处理帧次 = backbone 实际编码的帧数：锚点 3 跳 6 = 100 + 34 + 17 = 151；12/3 接力 = 130（与关键帧页同口径）

结论

History · 6 链 + 一跳（路径片段） 在 100 帧上超过 Point4D head 12/3 接力。avg_pts 0.665 vs 0.584（5 次打分标准差 0.003 / 0.004），逐段 72:25，EPE 0.90 vs 1.44 m，survival 也更高（71.4 vs 67.3）；5 个 20 帧区间里 5 个更高，最后 20 帧 0.539 vs 0.415。同一个 History：整段一条链 0.406，12/3 接力 0.508。

跳法不变，只把长片段换成路径片段，涨了 0.051。锚点 3 跳 6 原来锚点走跳帧片段、非锚点帧走 100 帧逐帧片段：0.603；每段路径单独组片段（帧 62 所在段 = [0, 6, …, 60, 61, 62]，memory 只有路径上的十几帧，锚点和逐帧跳出自同一次前向）：0.654，逐段 80:10，survival 60.6 → 70.0。段内位置 锚点 / +1 / +2 从 0.640 / 0.607 / 0.559 变成 0.656 / 0.657 / 0.646：逐帧跳几乎不再掉分。所以后段逐帧跳贵是长片段造成的，不是跳本身——History 训练片段只有 12 帧，checkpoint 的相对时间嵌入表 33 行里第 12–32 行全是 0（从没训到），100 帧片段后段一跳要在几十帧 memory 里找点；锚点和逐帧跳出自两次前向也可能有影响，这里没有分开。

再去掉段内逐帧链：6 链 + 一跳，又涨 0.011。锚点每 6 帧走 6 链，段内每帧从锚点直接一跳（跨 1–5 帧，每帧一个路径片段，每帧最多 17 跳、只有最后一跳不是跳 6）：avg_pts 0.665 vs 锚点 3 跳 6 路径片段 0.654，5 次打分每次都更高（差 +0.006–+0.015），逐段 61:11，survival 71.4。跨度大的一跳并不更差：跨 1 / 2 / 3 / 4 / 5 帧的帧分别是 0.654 / 0.660 / 0.663 / 0.674 / 0.670（6 链锚点帧 0.661）。处理帧次 814（每帧一个片段、共享前缀重算；backbone 没有 KV cache）。

锚点间隔是两种跳之间的取舍（长片段）。间隔 5 是 0.568，段内最多 4 跳逐帧、锚点链最多 19 跳；间隔 3 是 0.560，段内最多 2 跳，但锚点链最多 33 跳。间隔 3 前 40 帧最好（帧 1–39 0.718 vs 间隔 5 0.705），60 帧以后最差（0.394 vs 0.429）。锚点 3 跳 6 两头都占：段内最多 2 跳，锚点链最多 17 跳，每帧平均 9.4 跳（间隔 5 11.6、间隔 3 17.3），0.603。

长片段里锚点跳便宜、后段的逐帧跳贵。锚点帧（b = 0）越深越领先 Point4D：锚点 3 跳 6 走过 8–11 / 12–15 次锚点跳时 +0.075 / +0.102；但同一位置再逐帧走 2 跳就是 -0.038 / -0.035。间隔 5 在 12–15 次锚点跳处从 b = 0 的 +0.093 掉到 b = 4 的 -0.115，每逐帧一跳约 0.052；而整段一条链前 20 帧每跳只比 Point4D 多掉约 0.004。换成路径片段后同样位置是 +0.128（b = 0）/ +0.096（b = 2）。

锚点不要取平均。三种间隔取段内逐帧链和跳帧一跳的平均都更差（0.489 / 0.465 / 0.464）：跳帧一跳比段内逐帧链准得多，平均会把段内漂移带进锚点链。

跟拍和静态。静态相机（cam1）History · 6 链 + 一跳（路径片段） 0.622 vs Point4D 0.521：Point4D 输得多的段是 12/3 拼接把整段拼飞（EPE 几米），锚点走法全程在第 0 帧坐标系、没有拼接；跟拍（cam0）0.707 vs 0.647（长片段的锚点 3 跳 6 是 0.619）。逐段分位数 p10 0.409 vs 0.303、p90 0.870 vs 0.863。
