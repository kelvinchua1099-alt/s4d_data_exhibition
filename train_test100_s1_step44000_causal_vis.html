链式误差：系统偏差还是随机误差

结论：s4d_train 链式 motion_head 的误差以系统偏差为主，不是逐跳独立的随机误差。但它也不是一个全局常量偏差，而是按段变化、能持续 3 到 4 跳的偏差。下面用真值起点的预测做分解，checkpoint 为 step 44000，测试集 100 段，共 11 跳。

测法

每一跳回归的是相对上一跳的位移，再累加成位置。所以终点误差可以严格拆开：

E_t = E_0 + Σ_(k≤t) ε_k            ε_k = 第 k 跳预测位移 − 真值位移
E‖S_K‖² = Σ_k E‖ε_k‖²  +  2 Σ_(i<j) E[ε_i · ε_j]
          对角项：像独立误差     交叉项：跳间相关，即系统性累积
R = E‖S_K‖² / Σ_k E‖ε_k‖²       逐跳独立时 R ≈ 1，偏差一直不变时 R ≈ K
  1. 用真值起点，并且只用第 0 帧对齐。这样起点误差为零。整段一起拟合的 Sim(3) 会把段级的尺度和平移漂移吸收掉，所以这里不用。
  2. 算交叉项占比和 R。它们回答误差是否在跳与跳之间相关。
  3. 看不同间隔的跳之间误差的相关。它说明偏差能持续几跳。
  4. 按来源拆。分成三部分：所有段共有的常量、段内所有点共同的平移、点自己的误差。
  5. 每段用少量参数校正累积位移，看能消掉多少误差。参数有缩放、平移、3×3 线性变换。消得掉的部分就是和条件相关的系统偏差。
  6. 算反馈系数。它等于下一跳误差在已累积误差上的投影。负值说明模型会把误差拉回来，正值说明误差在放大。

去掉系统偏差后的上限（自估起点）

用本页的 s4d_train 预测，即因果、连续取帧、自 query 起点。第 0 帧的预测保持不动，只校正链累积出的位移，再用和主指标相同的 4RC 打分重算。除"全部段共用一个缩放"外，校正参数都是对每段用真值拟合的，所以给出的是上限，不是能直接做到的分数。每段约 3000 个点，这几十个参数拟合不了逐点独立的噪声，只能去掉段级的系统偏差。RANSAC 固定了种子，不校正一行比正式评测低 0.003。EPE 对 RANSAC 解很敏感，有一段因此从 0.63 m 变成 5.3 m，所以这里不报 EPE。

两种校正的定义。第 i 个点从第 0 帧到第 t 帧，预测的累积位移记为 Dp，真值的累积位移记为 Dg。校正只改 Dp，第 0 帧的起点不动。

Dp[t,i] = p[t,i] − p[0,i]          Dg[t,i] = g[t,i] − g[0,i]

每帧共同平移：
  b[t]     = mean_i ( Dp[t,i] − Dg[t,i] )          每帧一个 3 维向量，11 帧共 33 个参数
  Dp'[t,i] = Dp[t,i] − b[t]

3×3 线性 + 每帧共同平移：
  cp[t,i]  = Dp[t,i] − mean_i Dp[t,i]             先去掉每帧的平均位移
  cg[t,i]  = Dg[t,i] − mean_i Dg[t,i]
  A        = argmin Σ_(t,i) ‖A·cp[t,i] − cg[t,i]‖²    每段一个 3×3 矩阵，各帧共用，9 个参数
  Dp'[t,i] = A·cp[t,i] + mean_i Dg[t,i]            再加 33 个平移参数，共 42 个
  • 每帧共同平移修正的是整个人一起漂。每一帧算出段内所有点的平均误差，从每个点上减掉。修正后预测点云的重心轨迹和真值完全一致，但各点相对重心怎么动仍是模型自己的预测。比如第 5 帧整个人比真值落后 10 cm，就把所有点一起往前挪 10 cm。它对应上表的"段内共同平移"。
  • 3×3 线性修正的是各点相对重心的运动在形状上错得有规律。去掉每帧平均位移后，每段用一个矩阵把预测的相对位移映射到真值。它能表示幅度不对（比如四肢摆幅只预测出八成），各方向缩放不同（比如深度方向比横向压得更扁），以及运动方向的偏转和剪切。
  • 每段缩放加每帧平移是它的简化版。矩阵换成一个标量，只修幅度。
  • 这些校正只能去掉段级系统偏差。每段约 3000 个点，只有 33 到 42 个参数，修不了点与点之间不相关的随机误差，只能去掉整段共享、并且随位移线性变化的误差。
  • 所以表里的分数是上限。参数用真值拟合，部署时没法这样算。每帧平移逐帧拟合，也会顺带吸收一部分逐帧变化、不一定持续的共同误差，所以 0.781 和 0.814 比只去掉持续偏差能达到的分数略高。

还缺的两个实验

模型是确定性的，所以严格的"随机误差"需要人为制造样本分布。这两项要改一点代码，还要 GPU。

  • 输入扰动集成。对 query 像素抖 ±1 px 或加图像噪声，跑 N 次。各次之间的方差是随机部分，集成均值的误差是系统部分。
  • 每跳都喂真值位置。现在的 teacher forcing 只作用在起点。每跳都给真值输入，能把单跳本身的误差和喂回自身预测造成的误差分开。
  • 已有的多路径平均不能用来判断。np5、np10 的随机路线会跨 2 帧，跳的分布变了，分数也是变差的。
